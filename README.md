# Phone Detection in Classroom – AI Surveillance System

## Overview
This project is an AI-based classroom surveillance system that detects mobile phone usage in real time using computer vision.

## Features
- Real-time phone detection
- Live camera monitoring
- AI-based object detection
- Automatic detection alerts

## Technologies Used
- Python
- YOLOv8
- OpenCV
- HTML
- Flask

## Project Structure
- app.py
- model.py
- requirements.txt
- yolov8n.pt

## Installation

1. Clone the repository
2. Install dependencies
3. Run:
```
python app.py
```
